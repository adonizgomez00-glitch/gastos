### 3.4 Detalles críticos para no fallar

- **AC-03 math**: `(500 * 7703054 + 500_000) / 1_000_000` trunc → **3852** (half-up en `TransactionService._convert`).
- **AC-09**: `AccountRepository.findById(spaceId, id)` filtra por espacio → `null` → `NotFoundError` 404. Correcto para I-07.
- **AC-10**: `clearRates` + `_providers = [fakeProvider('er-api', null), fakeProvider('banguat', null)]` + POST USD.
- **AC-11**: no confundir con AC-10; seed carry-forward en `exchange_rates` con fecha pasada.
- **AC-13**: auditar con `auditRepository.listByEntity('transactions', txnId)`; acción `update`; `before` y `after` no null.
- **AC-15**: refund devuelve **201** (no 200); `refundOf` = id original; original queda `archived=true`. También: re-archivar/recibir refund de archivada → 422 `TRANSACTION_ARCHIVED`.
- **AC-16**: `GET /api/transactions/:id` con id de otro espacio → 404. Para el list: insertar fila con otro `space_id` vía SQL directo (como hacen accounts AC-07).
- **AC-17**: no hay endpoint de reportes aún (SPEC-009); llamar **servicio** `transactionService.sumByCategory`. Solo cuenta `kind='expense'` y `archived=0`.
- **AC-18**: el service valida formato `YYYY-MM-DD` y lo guarda tal cual (`validateOccurredOn`); no convierte a UTC. Enviar fecha y verificar persistencia.
- **AC-19**: `list` ordena `occurred_on DESC, created_at DESC`; `includeArchived` solo si query `= '1'`.
- **`description`**: SPEC dice NOT NULL; `validateDescription` devuelve `''` para vacío → SQLite acepta string vacío. **Posible defecto**: si el AC/exigencia es "obligatoria", un POST sin description podría pasar. Si al escribir el test aparece, **reportar defecto**, no relajar el test.
- **No hay `DELETE /api/transactions`** en las rutas (SPEC §9 no lo incluye; `API.md` §6.6 lo menciona — discrepancia docs, no bloquea tests de ACs).
- **`categoryId` opcional** en el service (`input.categoryId ? ... : null`); los ACs de SPEC-004 siempre pasan categoría — usarla siempre en el setup.
- **Descripción de refund**: `Reembolso: <desc>`; `notes` incluye `Reembolso de #<id>`.
